게시글 수정

관리자 권한으로 게시글 내용, 연락처, 위치 정보를 수정합니다.

수정 후 상세 화면과 목록 화면에 바로 반영됩니다.

게시글 카테고리를 바꾸면 진행 상태도 해당 카테고리의 기본 상태로 맞춰집니다. 반환 완료 글은 반환 완료 상태를 유지합니다.

등록된 사진이 없습니다.

이번 수정에서는 텍스트와 위치 정보를 조정합니다.

전화번호는 로그인한 사용자에게만 상세 화면에서 표시됩니다.

기존 좌표가 지도에 표시됩니다. 다른 위치를 클릭하면 게시글 좌표가 변경됩니다.
